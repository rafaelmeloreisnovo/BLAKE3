# RMR Portable Legal State V1

State: PROSPECTIVE_SOURCE_AVAILABLE / COUNSEL_REVIEW_RECOMMENDED

## Active boundary

The new license applies only to files that explicitly carry:

```text
SPDX-License-Identifier: LicenseRef-RMR-Individual-Research-1.0
```

and to paths explicitly mapped to that license.

It does not retroactively revoke older grants under `rmr/LICENSE_RMR`, and it
does not restrict upstream BLAKE3.

## Intended permission model

```text
individual_personal_noncommercial_research = PERMITTED
institutional_research = WRITTEN_LICENSE_REQUIRED
commercial_use = WRITTEN_LICENSE_REQUIRED
OEM/SDK/API/paid_service = WRITTEN_LICENSE_REQUIRED
redistribution = NOT_GRANTED_BY_PUBLIC_LICENSE
```

## Brazil-oriented legal boundary

Technical implementation cannot create a government fine or court remedy.
Contractual audit/cost/penalty rights must be tied to a signed agreement where
required and remain subject to mandatory law and judicial control.

The public license deliberately sets:

```text
automatic_contractual_penalty = NONE
penalty_amount = TOKEN_VAZIO_ORDER_FORM
automatic_attorney_fee_shift = NONE
automatic_private_system_audit = NONE
```

## Upstream boundary

```text
BLAKE3 algorithm/source/vectors = UPSTREAM RIGHTS
RMR Portable envelope/API/tests/docs = PROJECT-AUTHORED NEW MATERIAL
```

## Counsel gate

Before a material commercial/institutional enforcement campaign, obtain
jurisdiction-specific review of:
- license formation/assent;
- ownership/contributor history;
- prior grants;
- audit clause;
- penalty/liquidated-damages clause;
- forum/governing law;
- fee shifting;
- evidence collection/privacy.
